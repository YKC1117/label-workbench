# Native primitive/HRI contract review

Baseline Run45 remains the passing Text/barcode renderer. This work adds no production capability until a real native geometry/persistence/visual gate is complete.

No generic claim that all Create contexts work.

The integrated candidate retains Designer Text pool + BTC and adds typed Create2/3/6 only inside the proven document context. Graphics must have the exact expected native root and zero DataSources; that is a separate typed source contract, not a blanket source-isolation exemption. All retained peers keep XML/COM checks, and Picture peers additionally require unchanged actual bitmap SHA because image bytes are not exposed in GetXML. Geometry/image challenges must visibly change the object, then restore exact XML and bitmap; image assets are hidden before a distinct-process reopen and exact object/format BMP comparison. A cold failure quarantines the BTW and removes accepted output aliases.

Canonical semantics: Box x/y/width/height describe stroke centerline rectangle; expected ink includes half the stroke on each side. Line x/y is unrotated start of local path, width/height its endpoint vector; the adapter uses endpoint setters and explicitly checks the resulting Center anchor/absolute angle, rather than misusing X/Y as top-left. Only upright primitive models are enabled in this candidate. Images currently require embedded monochrome non-interlaced 8-bit PNG, measured 300x300dpi driver, and an independent declared-image pattern check. Resampling has a one-driver-dot bound (2 export pixels at 600dpi), measured from real Windows PrinterSettings; this is independent of unchanged .5mm physical geometry gates. Missing/other driver resolution fails closed. Run47's source mask vs native raster shows edge dither at up to this bound; wrong image content is rejected. Original text/barcode optical tolerances are unchanged.

Visible HRI is a restricted native Arial12/center profile with explicit canonical gap1.1mm and caption-frame height. Other typography/gaps/rotation remain blocked. Actual stable bar band and caption ink are segmented from native bitmap and compared separately: symbol footprint/bar height, caption center/top/containment, effective HRI value, Save/reopen font/visibility/value and strict challenge coupling. No free width/height stretching.

A hollow border can legally enclose text. Its full per-object white interior is not a comparable transparency constraint. Registration therefore requires every actual border ink pixel, globally unique; an independent hollow/stroke/edge-content gate rejects filled or malformed borders. Duplicate/missing patterns remain unresolved. Quiet-zone checks use border stroke ink rather than a falsely filled AABB. New regressions cover these positive and negative cases. No gate tolerance has been raised to accept misplacement.

Remaining: native paragraph/fixed Text justification, color/JPEG/interlaced/indexed images, rotated primitives and arbitrary native HRI styling are not enabled. New mixed candidate runtime must pass before any new capability is reported as verified.
